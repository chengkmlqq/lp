# Excel导入功能实现总结

## 实现内容

### 1. 核心功能模块

#### `/web/src/lib/excel-import-utils.ts`
实现了Excel导入的核心功能：

**主要函数：**
- `parseExcelFile(file: File)` - 解析Excel文件并返回表单数据
- `generateImportTemplate()` - 生成并下载Excel导入模板

**功能特性：**
- 支持 `.xlsx` 和 `.xls` 格式
- 自动字段映射（21个字段）
- 数据类型自动转换（数值、字符串）
- 重合闸状态映射（中文→英文代码）
- 完整的错误处理

### 2. 表单组件更新

#### `/web/src/components/fault-analysis/create-analysis-form-advanced.tsx`
在故障信息表单中集成Excel导入功能：

**新增UI元素：**
- "下载模板"按钮 - 带下载图标
- "Excel导入"按钮 - 带上传图标
- 使用Ant Design的Upload组件

**交互逻辑：**
- 点击下载模板 → 自动下载Excel文件
- 选择Excel文件 → 自动解析并填充表单
- 显示成功/失败提示消息

### 3. 支持的字段

导入模板支持以下21个字段：

**必填字段：**
- 录波记录厂站
- 故障时刻
- 故障线路名称
- 故障相
- 故障持续时间(ms)
- 重合闸情况

**可选字段：**
- 故障相电压(V)
- 故障相电流(A)
- 最大零序电流(A)
- 零序补偿系数K
- 故障电阻Rm(Ω)
- 线路总长度L(km)
- 线路正序灵敏角(°)
- 线路正序阻抗定值(Ω)
- 雷电流幅值I(kA)
- 雷电定位经度(°)
- 雷电定位纬度(°)
- 录波测距(km)
- 行波测距(km)
- 光学接闪位置
- 光学设备安装位置

## 使用方法

### 1. 下载模板
点击"下载模板"按钮，获取标准Excel模板文件：`故障信息导入模板.xlsx`

### 2. 填写数据
在Excel中按照模板格式填写数据：
- 第一行：保持表头不变
- 第二行：填写实际数据
- 日期格式：`YYYY-MM-DD HH:mm:ss.SSS`
- 重合闸情况：`成功`、`失败`或`不适用`

### 3. 导入数据
1. 点击"Excel导入"按钮
2. 选择填写好的Excel文件
3. 系统自动解析并填充表单
4. 检查填充的数据

### 4. 确认提交
导入后可以手动调整任何字段，然后提交表单。

## 错误处理

### 文件读取错误
```
✗ 导入失败: 读取文件失败
```
**原因：** 文件格式不正确或文件损坏
**解决：** 确保文件为`.xlsx`或`.xls`格式

### 格式错误
```
✗ 导入失败: Excel文件格式不正确，至少需要包含表头和一行数据
```
**原因：** Excel文件没有数据行
**解决：** 确保Excel包含表头和至少一行数据

### 部分字段未填充
**原因：** 表头名称不匹配
**解决：** 使用下载的标准模板，不要修改表头名称
