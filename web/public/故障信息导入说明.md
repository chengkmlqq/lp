# 故障信息Excel导入说明

## 功能说明

故障分析表单支持通过Excel导入故障信息数据，快速填充表单字段。

## 使用步骤

1. **下载模板**：点击"下载模板"按钮，下载Excel导入模板文件
2. **填写数据**：在Excel模板中填写故障信息数据
3. **导入数据**：点击"Excel导入"按钮，选择填写好的Excel文件
4. **确认数据**：系统自动填充表单，检查数据是否正确

## 注意事项

1. **Excel格式要求**：
   - 支持 `.xlsx` 和 `.xls` 格式
   - 第一行必须是表头（字段名）
   - 第二行为数据行
   - 表头名称必须与模板完全一致

2. **数据填写规范**：
   - 必填字段不能为空
   - 数值字段请填写数字，不要包含单位
   - 日期时间格式：`YYYY-MM-DD HH:mm:ss.SSS`
   - 重合闸情况只能填写：成功、失败、不适用

3. **故障相选项**：
   - 单相故障：A, B, C
   - 单相接地：AN, BN, CN
   - 两相故障：AB, BC, AC
   - 三相故障：ABC
   - 两相接地：ABN, BCN, ACN

4. **导入后**：
   - 请仔细检查导入的数据是否正确
   - 可手动修改任何字段
   - 未填写的字段可在表单中补充

## 故障排除

### 导入失败
- 检查文件格式是否为 `.xlsx` 或 `.xls`
- 确认表头名称与模板一致
- 确认至少有一行数据

### 数据未填充
- 检查Excel中的表头是否与模板完全一致
- 确认数据行不为空
- 查看浏览器控制台的错误信息

### 数值字段显示异常
- 确认Excel中该字段填写的是数字
- 删除数值中的单位符号
- 使用标准数字格式（支持小数点）
