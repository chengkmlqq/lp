## 🚀 使用方法

### 用户操作流程

1. **打开故障分析页面**
   - 导航到故障分析模块
   - 点击"新建分析"按钮

2. **下载Excel模板**
   ```
   点击 "下载模板" 按钮
   ↓
   获得 "故障信息导入模板.xlsx" 文件
   ```

3. **填写Excel数据**
   - 在Excel中填写故障信息
   - 保持第一行表头不变
   - 在第二行填写数据

4. **导入数据**
   ```
   点击 "Excel导入" 按钮
   ↓
   选择填写好的Excel文件
   ↓
   系统自动解析并填充表单
   ↓
   显示成功提示
   ```

5. **检查和提交**
   - 检查自动填充的数据
   - 手动调整（如需要）
   - 提交表单

## 🔧 技术细节

### 支持的文件格式
- `.xlsx` (Excel 2007+)
- `.xls` (Excel 97-2003)

### 支持的字段（21个）

#### 必填字段
- 录波记录厂站
- 故障时刻
- 故障线路名称
- 故障相
- 故障持续时间(ms)
- 重合闸情况

- 最大零序电流(A)
- 零序补偿系数K
- 故障电阻Rm(Ω)
- 线路总长度L(km)
- 线路正序灵敏角(°)
- 线路正序阻抗定值(Ω)
- 雷电流幅值I(kA)

### 数据类型转换

| Excel中的值 | 转换后 |
|------------|--------|
| 成功 | success |
| 失败 | failed |
| 不适用 | not_applicable |
| 37.04 | 37.04 (number) |
| "64" | 64 (number) |

## 🐛 常见问题

### 导入失败：读取文件失败
**原因：** 文件格式不正确或文件损坏
**解决：** 确保文件是 `.xlsx` 或 `.xls` 格式

### 导入失败：格式不正确
**原因：** Excel缺少表头或数据行
**解决：** 使用下载的标准模板

### 部分字段未填充
**原因：** 表头名称不匹配
**解决：** 不要修改表头名称，使用标准模板

### 数值字段显示为文本
**原因：** Excel中字段格式为文本
**解决：** 在Excel中设置单元格格式为"数值"

## 💡 提示和技巧

### 提示1：使用标准模板
始终从"下载模板"按钮获取最新的标准模板，避免字段不匹配。

### 提示2：检查日期格式
确保日期时间格式为：`YYYY-MM-DD HH:mm:ss.SSS`
例如：`2023-03-27 20:20:31.939`

### 提示3：重合闸状态
只能填写以下三个值之一：
- 成功
- 失败
- 不适用

### 提示4：数值字段
数值字段不要包含单位，只填写数字。
- ✅ 正确：`64`
- ❌ 错误：`64ms`

### 提示5：可选字段
可选字段可以留空，系统会跳过空值。
