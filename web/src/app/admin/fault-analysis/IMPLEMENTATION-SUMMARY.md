## ✨ 功能特性

### 主页面功能
1. **故障分析列表**
   - 3个模拟数据记录
   - 卡片网格展示（响应式 1-3 列）
   - 状态徽章（待处理/处理中/已完成/失败）
   - 风险等级标识（低/中/高/严重）

2. **搜索过滤**
   - 实时搜索
   - 支持按标题、线路名称、描述过滤

3. **详情查看**
   - 基本信息展示
   - 分析参数（JSON 格式）
   - 分析结果（JSON 格式）

4. **新建分析**
   - 模态框表单
   - 权限控制（需要 line.manage 权限）

### 表单设计（三步骤）

#### ① 故障线路
- 线路选择下拉框（支持搜索）
- 必填验证

#### ② 故障信息
- **Excel 导入按钮**（右上角）
- **基础信息**（5个字段）
  - 录波记录厂站、故障时刻、故障线路名称、故障相、故障持续时间
- **电气参数**（6个字段）
  - 重合闸情况、故障相电压/电流、零序电流/补偿系数、故障电阻
- **线路参数**（3个字段）
  - 线路长度/灵敏角/阻抗定值
- **雷电定位**（3个字段）
  - 雷电流幅值、经纬度
- **测距数据**（2个字段）
  - 录波测距、行波测距
- **光学监控**（2个字段）
  - 接闪位置、设备安装位置

#### ③ 分析数据
- **4个文件上传卡片**（2x2 网格）
  - 录波数据（.txt）
  - 雷电定位数据（.xls/.xlsx）
  - 分布式行波数据（.csv/.dat）
  - 光学监控数据（图片/视频）

## 🎨 设计实现细节

### 颜色系统
- **状态徽章**
  - 待处理：灰色
  - 处理中：蓝色（processing）
  - 已完成：绿色（success）
  - 失败：红色（error）

- **风险等级**
  - 低风险：绿色
  - 中风险：黄色
  - 高风险：红色
  - 严重：深红色

### 布局特点
- **响应式设计**：支持桌面和移动端
- **步骤标题栏**：深色背景 + 白色文字
- **表单字段**：1/2/3 列自适应布局
- **文件上传**：卡片式设计，图标 + 文字说明

## 🚀 使用方法

### 访问路径
```
/admin/fault-analysis
```

### 操作流程
1. 进入页面查看故障分析列表
2. 使用搜索框过滤记录
3. 点击卡片查看详细信息
4. 点击"新建分析"打开表单
5. 填写三步骤表单内容
6. 提交创建新的故障分析
