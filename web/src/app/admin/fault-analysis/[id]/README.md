## ✨ 功能特性

### 1. 详情报告页面

#### 页面结构
- **报告头部**
  - 故障编号：FA-2026-0703-001 故障分析报告
  - 状态标签：待复核（橙色）
  - 导出报告按钮
  - 返回按钮

- **基本信息栏**
  - 线路名称
  - 录波记录厂站
  - 故障时间

#### 报告内容（四大章节）

**一、故障初判（录波分析）**
- 录波数据查询信息
- 故障特征分析（列表形式）
  - A相电流突增
  - A相电压明显跌落
  - 零序电流及零序电压显著增大
- 故障类型判定
- 故障阻抗计算（橙色高亮）
- 故障性质判定
- 综合分析结论

**二、故障定位（雷电定位、录波测距、行波测距）**
- 录波测距结果
- 行波测距结果
- 雷电定位数据

**三、故障原因分析**
- ① 故障区段线路台账参数
  - 地形类型、海拔、杆塔型号
  - 绝缘子串长度、接地电阻
  - 耐雷水平计算
  - 绕击概率判定
  
- ② 分布式行波监测数据
  - 监测装置信息
  - 行波特征分析
  - 雷击判定
  - 绕击判定
  
- ③ 光学监控装置分析
  - 光学监控记录
  - 图像识别结果
  
- ④ 综合融合判别
  - 台账分析置信度
  - 行波分析置信度
  - 光学监测置信度
  - 一致性评分
  - 最终置信度分布

**四、最终判定结果**
- 结果卡片（灰色背景）
  - 故障类型
  - 故障定位
  - 雷击类型（橙色高亮）
  - 冲突来源
  
- 决策建议卡片（白色背景，粗边框）
  - 决策建议标题
  - 置信度判定
  - 人工复核建议（橙色加粗）

### 2. 访问方式

#### 方式一：主列表页面跳转
1. 进入故障分析列表页 `/admin/fault-analysis`
2. 点击任意卡片查看简要详情
3. 点击"查看完整报告"按钮
4. 在新标签页打开完整报告

#### 方式二：直接访问
- URL: `/admin/fault-analysis/[id]`
- 例如: `/admin/fault-analysis/1`

## 🎨 设计实现细节

### 视觉样式

1. **章节标题栏**
   - 深色背景（bg-slate-900）
   - 白色文字
   - 圆角设计
   - 内边距舒适

2. **内容布局**

   - 居中显示
   - 灰色背景（bg-gray-50）

3. **文本样式**
   - 正常文本：gray-700
   - 子标题：加粗

4. **卡片样式**
   - 灰色背景（bg-gray-50）
   - 边框（border-gray-200）

### 交互功能

- **返回按钮**：返回上一页
- **导出报告**：触发报告导出（预留功能）
- **新标签页打开**：不影响主列表页状态

## 🔧 技术实现

### 路由设计
- 使用 Next.js 动态路由：`[id]`
- 从 URL 参数获取分析ID
- 支持直接访问和程序化跳转

### 数据渲染
- 使用 React Query 数据获取
- 加载状态处理
- 错误状态处理
- 权限检查

### 内容渲染
- 灵活的内容类型系统：
  - `text` - 普通文本
  - `subtitle` - 子标题
  - `bullet` - 列表项
  - `highlight` - 高亮文本
  - `card` - 卡片内容
- 动态渲染不同类型的内容块

## 🎯 完整功能流程

1. **用户在列表页**
   - 查看 3 条故障分析记录
   - 点击卡片查看简要详情

2. **查看简要详情**
   - 基本信息
   - 状态和风险标签
   - 简单的参数和结果（JSON）

3. **点击"查看完整报告"**
   - 在新标签页打开
   - 显示完整的 4 章节报告
   - 专业的报告排版

4. **在详情页操作**
   - 阅读完整分析报告
   - 点击"导出报告"下载
   - 点击"返回"关闭标签页
