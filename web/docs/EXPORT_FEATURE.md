# 故障分析详情页导出功能

## 功能概述

故障分析详情页面现已支持将完整的故障分析报告导出为 PDF 和 Word 格式。

## 使用方法

1. 访问故障分析详情页面：`http://223.109.142.84:3002/fault-analysis/[id]`
2. 点击页面右上角的"导出报告"按钮
3. 在下拉菜单中选择导出格式：
   - **导出为 PDF**：生成高质量PDF文档，保留页面样式
   - **导出为 Word**：生成可编辑的Word文档（.docx格式）

## 导出内容

导出的文档包含完整的故障分析报告内容：

- 报告标题和基本信息（故障ID、线路名称、厂站、故障时间）
- 一、故障初判（录波分析）
- 二、故障定位（雷电定位、录波测距、行波测距）
- 三、故障原因分析
- 四、最终判定结果

## 技术实现

### 依赖库

- **jspdf**: PDF生成
- **html2canvas**: HTML转图片
- **docx**: Word文档生成
- **file-saver**: 文件下载

### 核心文件

- `/web/src/lib/export-utils.ts`: 导出功能工具函数
- `/web/src/app/admin/fault-analysis/[id]/page.tsx`: 故障分析详情页面

### PDF导出逻辑

1. 使用 `html2canvas` 将指定的DOM元素（id="export-content"）转换为canvas图片
2. 使用 `jspdf` 将图片转换为PDF文档
3. 自动处理分页，支持多页内容

### Word导出逻辑

1. 解析故障分析报告的数据结构
2. 使用 `docx` 库按照文档格式要求生成Word文档
3. 支持标题、段落、列表、高亮文本等多种格式
4. 使用 `file-saver` 触发浏览器下载

## 样式保持

- PDF导出会保留页面的视觉样式（颜色、字体、布局）
- Word导出会尽可能保持文档结构，但样式会适配Word格式

## 文件命名

导出的文件名格式为：`[故障ID]_故障分析报告.[pdf/docx]`

例如：`FA-2026-0703-001_故障分析报告.pdf`

## 注意事项

1. 导出功能需要浏览器支持，建议使用Chrome、Edge、Firefox等现代浏览器
2. PDF导出时会将整个报告转换为图片，因此文件大小可能较大
3. Word导出的文档可以直接编辑，适合需要修改内容的场景
4. 导出过程中页面会显示加载状态，请耐心等待
