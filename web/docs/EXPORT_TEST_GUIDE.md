# 故障分析导出功能测试指南

## 快速测试步骤

### 1. 访问详情页面
在浏览器中打开：
```
http://223.109.142.84:3002/fault-analysis/[任意ID]
```

或本地开发环境：
```
http://localhost:3001/admin/fault-analysis/[任意ID]
```

### 2. 测试PDF导出
1. 点击页面右上角的"导出报告"按钮
2. 选择"导出为 PDF"
3. 浏览器应自动下载PDF文件
4. 打开PDF文件，检查：
   - ✅ 标题和基本信息正确显示
   - ✅ 所有章节内容完整
   - ✅ 样式保持一致（颜色、字体、布局）
   - ✅ 分页正常（如果内容超过一页）

### 3. 测试Word导出
1. 点击页面右上角的"导出报告"按钮
2. 选择"导出为 Word"
3. 浏览器应自动下载.docx文件
4. 用Microsoft Word或WPS打开文件，检查：
   - ✅ 标题和基本信息正确显示
   - ✅ 章节标题格式正确
   - ✅ 列表项正确显示
   - ✅ 高亮文本（橙色）正确显示
   - ✅ 文档可以正常编辑

### 4. 检查文件名
导出的文件名应为：`[故障ID]_故障分析报告.[pdf/docx]`

例如：
- `FA-2026-0703-001_故障分析报告.pdf`
- `FA-2026-0703-001_故障分析报告.docx`

### 5. 测试错误处理
- 在导出过程中，按钮应显示加载状态
- 导出成功后，应显示成功提示消息
- 如果导出失败，应显示错误提示消息

## 预期结果

### PDF导出预期内容
- 报告头部：故障ID、线路名称、厂站、故障时间
- 第一章：故障初判（录波分析）
- 第二章：故障定位
- 第三章：故障原因分析
- 第四章：最终判定结果

### Word导出预期格式
- 一级标题：报告标题（居中）
- 普通段落：基本信息
- 二级标题：各章节标题
- 列表：带项目符号的内容
- 高亮文本：橙色加粗文本
- 缩进段落：卡片内容

## 常见问题排查

### 问题1：导出按钮无响应
- 检查浏览器控制台是否有错误
- 确认页面数据已加载完成
- 尝试刷新页面后重新导出

### 问题2：PDF文件打不开
- 检查文件大小是否正常（不应为0KB）
- 尝试使用不同的PDF阅读器
- 检查浏览器是否阻止了下载

### 问题3：Word文件格式错误
- 确认使用的是Microsoft Word 2010或更高版本
- 尝试使用WPS Office打开
- 检查文件扩展名是否为.docx

### 问题4：导出内容不完整
- 检查页面内容是否完全加载
- 等待所有动画和图片加载完成后再导出
- 检查控制台是否有网络请求失败
